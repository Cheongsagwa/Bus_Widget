============================================================
 노선 시간표 DB
============================================================

■ 파일 하나 = 노선 하나
  이 폴더(app/src/main/assets/timetables)에 "노선번호.txt" 파일을 만들면
  앱의 노선 세부 확장창 → [시간표 보기]에 그대로 나옵니다.

  파일 이름 예)
    300.txt
    7.txt
    서면5(서면100).txt   ← 앱에 보이는 번호 그대로
    서면5.txt            ← 괄호 앞 번호만 써도 찾음
    CCB250000001.txt     ← 같은 번호 노선이 여럿이면 노선 ID 로 구분 (먼저 찾음)

  춘천 시내버스 전 노선(간선 · 지선 · 대학병원 · 통학급행 S · 읍면 마을버스)의
  빈 파일을 미리 만들어 두었습니다. [기점발] / [종점발] 아래에 시각만 채우면 됩니다.
  (노선 목록은 나무위키 '춘천시 시내버스' 기준이라 빠진 노선이 있을 수 있습니다)

  비교할 때 공백 · 영문 대소문자 · "S-1"/"S1" 차이는 무시합니다.
  시각을 안 채운 노선은 "등록된 시간표가 없습니다" 가 표시되고,
  파일이 아예 없는 노선은 그 아래에 만들어야 할 파일 이름이 함께 나옵니다.

■ 파일 형식 (UTF-8 로 저장)

  # 으로 시작하는 줄은 메모 (앱에 안 나옴)

  [종점발(춘천시청별관)]       ← 대괄호 = 표 제목 (회색 머리줄)
  06:40 07:00 07:20 07:40      ← 시각은 띄어쓰기 · 쉼표 · 줄바꿈 아무거나로 구분
  8:00, 8:20                   ← 6:40 처럼 써도 06:40 으로 맞춰 줌

  [기점발(춘천시청별관)]       ← 제목을 새로 쓰면 표가 하나 더 생김
  06:09 06:21 ...

  [S노선 · 종점발]             ← S노선 · 편도노선 등 별도 시간표도 표를 하나 더 만들면 됨
  09:10 13:40

  > 주말 · 공휴일은 감축 운행   ← > 로 시작하면 표 아래 흐린 안내문

  표는 한 줄에 5칸씩, 적은 순서대로 왼쪽 → 오른쪽, 위 → 아래로 채워집니다.

■ 고친 뒤
  앱을 다시 빌드(실행)해야 반영됩니다.

■ 참고
  _예시.txt 는 형식 예시입니다. (밑줄로 시작하는 파일은 어떤 노선과도 연결되지 않음)
